# Dart Fundamentals – Practice Exercises

This repository contains a collection of exercises developed while learning Dart as part of the course *"Flutter – Móvil: De cero a experto"*.

## Overview

The objective of this repository is to build a solid foundation in Dart, progressing from basic syntax to more advanced concepts such as object-oriented programming and asynchronous programming.

Each exercise focuses on a specific concept and is designed to reinforce understanding through simple and clear implementations.

## Contents

The exercises are organized progressively and cover:

### Basics
- Program structure (`hello_world`)
- Variables and data types

### Collections and Control Flow
- Maps, lists, and iterables
- Basic data manipulation

### Functions
- Function definitions
- Parameters and return values

### Object-Oriented Programming
- Classes
- Named constructors
- Getters and setters
- Abstract classes
- Mixins

### Asynchronous Programming
- Futures
- Async / Await
- Error handling (`try / catch / finally`)
- Streams
- Stream consumption and handling

## Purpose

These exercises are part of my learning path toward mobile development.  
The focus is on understanding core programming concepts that will later be applied in Flutter applications.

## Notes

- All exercises are written in Dart  
- Code prioritizes readability and understanding  
- Each file represents a small, isolated practice
