# Fundamentos de Dart – Ejercicios prácticos

Este repositorio contiene una colección de ejercicios desarrollados durante el aprendizaje de Dart como parte del curso *"Flutter – Móvil: De cero a experto"*.

## Descripción general

El objetivo de este repositorio es construir una base sólida en Dart, progresando desde la sintaxis básica hasta conceptos más avanzados como la programación orientada a objetos y la programación asíncrona.

Cada ejercicio se centra en un concepto específico y está diseñado para reforzar su comprensión mediante implementaciones simples y claras.

## Contenidos

Los ejercicios están organizados de forma progresiva y cubren:

### Fundamentos
- Estructura básica de un programa (`hello_world`)
- Variables y tipos de datos

### Colecciones y control de flujo
- Maps, listas e iterables
- Manipulación básica de datos

### Funciones
- Definición de funciones
- Parámetros y valores de retorno

### Programación orientada a objetos
- Clases
- Constructores con nombre
- Getters y setters
- Clases abstractas
- Mixins

### Programación asíncrona
- Futures
- Async / Await
- Manejo de errores (`try / catch / finally`)
- Streams
- Consumo y gestión de streams

## Objetivo

Estos ejercicios forman parte de mi camino de aprendizaje hacia el desarrollo de aplicaciones móviles.  
El enfoque está en comprender los conceptos fundamentales de programación que posteriormente se aplicarán en aplicaciones Flutter.

## Notas

- Todos los ejercicios están desarrollados en Dart  
- El código prioriza la claridad y la comprensión  
- Cada archivo representa una práctica pequeña e independiente  

## Próximos pasos

- Aplicar estos conceptos en aplicaciones reales con Flutter  
- Trabajar con APIs y gestión de estado  
- Desarrollar funcionalidades completas siguiendo arquitecturas limpias
