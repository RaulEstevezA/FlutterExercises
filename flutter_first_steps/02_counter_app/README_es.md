# Flutter Counter App

Este proyecto es una aplicación sencilla en Flutter que implementa un contador con lógica básica e interacción con el usuario.

## Descripción general

La aplicación permite incrementar y decrementar un valor numérico, aplicando ciertas restricciones y comportamientos dinámicos:

- El contador no puede bajar de 0  
- Cuando el contador alcanza el valor 1, el texto mostrado cambia dinámicamente  

Este proyecto está enfocado en comprender la gestión del estado y la interacción del usuario en Flutter.

## Conceptos clave

- Uso de StatefulWidget para gestionar estado dinámico  
- Actualización de la interfaz en función del estado  
- Gestión de eventos mediante botones  
- Renderizado condicional según el valor del contador  
- Implementación de lógica básica de aplicación  

## Funcionalidades

- Incrementar contador  
- Decrementar contador (con límite inferior en 0)  
- Cambio dinámico del texto cuando el contador es igual a 1  

## Tecnologías

- Flutter  
- Dart  

## Objetivo

Este proyecto amplía los conceptos básicos de Flutter introduciendo widgets con estado y lógica de aplicación sencilla.

El enfoque está en entender cómo las interacciones del usuario afectan a la interfaz y cómo se gestiona el estado dentro de la aplicación.
