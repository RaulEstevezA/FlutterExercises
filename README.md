# Flutter Exercises

This repository collects Dart and Flutter practice projects created while following the Udemy course [Flutter - Móvil, de cero a experto](https://www.udemy.com/share/108tHI3@8sApsSM5gRVpUMMrnp39BJx3HNJDwtyam4i83c8nx7qDcwuEhSUUOAnGUIPy6KvRYA==/).

The goal of the repository is to document a learning path from Dart fundamentals to complete Flutter exercises. Each folder contains focused practice projects with their own README files, screenshots, notes, and implementation details.
