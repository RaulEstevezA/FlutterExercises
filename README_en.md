# Flutter Exercises - Repository Overview

This repository brings together the exercises and small projects I am building while learning Dart and Flutter through the Udemy course [Flutter - Móvil, de cero a experto](https://www.udemy.com/share/108tHI3@8sApsSM5gRVpUMMrnp39BJx3HNJDwtyam4i83c8nx7qDcwuEhSUUOAnGUIPy6KvRYA==/).

It is organized as a learning path: first the Dart language fundamentals, then several Flutter applications that introduce widgets, state, navigation, external packages, API consumption, assets, video playback, and app structure. The README inside each project contains the detailed explanation for that specific exercise, so this file stays as a general map of the repository.

## Projects

### Dart Introduction

- [Dart Fundamentals - Practice Exercises](dart_introduction/README.md)

This section focuses on the language foundations needed before building Flutter apps. It includes exercises about program structure, variables, collections, functions, object-oriented programming, asynchronous programming, futures, streams, and error handling.

### Flutter First Steps

The `flutter_first_steps` folder contains the first Flutter applications in the repository. These projects move progressively from a minimal app to more complete interfaces and app flows:

- [Flutter Hello World App](flutter_first_steps/01_hello_world_app/README.md)
- [Flutter Counter App](flutter_first_steps/02_counter_app/README.md)
- [Maybe App](flutter_first_steps/03_maybe_app/README.md)
- [Tok Tik](flutter_first_steps/04_tok_tik/README.md)
- [Widget App](flutter_first_steps/05_widget_app/README.md)
- [Forms App](flutter_first_steps/06_forms_app/README_en.md)

These exercises cover the basic structure of Flutter projects, stateless and stateful widgets, Material components, interaction, simple business logic, state management, API requests, local assets, video playback, navigation, theming, reusable UI pieces, package usage, and form validation.

## Purpose

The repository is mainly a practical record of my progress as a Flutter developer. The projects are not meant to be production apps; they are focused exercises designed to understand concepts, compare approaches, and build a solid base for larger mobile applications.
