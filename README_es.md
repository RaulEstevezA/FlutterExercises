# Flutter Exercises - Descripción general del repositorio

Este repositorio reúne los ejercicios y pequeños proyectos que estoy desarrollando mientras aprendo Dart y Flutter con el curso de Udemy [Flutter - Móvil, de cero a experto](https://www.udemy.com/share/108tHI3@8sApsSM5gRVpUMMrnp39BJx3HNJDwtyam4i83c8nx7qDcwuEhSUUOAnGUIPy6KvRYA==/).

Está organizado como un camino de aprendizaje: primero los fundamentos del lenguaje Dart y después varias aplicaciones Flutter que introducen widgets, estado, navegación, paquetes externos, consumo de APIs, assets, reproducción de video y estructura de aplicaciones. El README de cada proyecto contiene la explicación detallada de ese ejercicio concreto, por lo que este archivo funciona como mapa general del repositorio.

## Proyectos

### Introducción a Dart

- [Fundamentos de Dart - Ejercicios prácticos](dart_introduction/README_es.md)

Esta sección se centra en las bases del lenguaje necesarias antes de construir aplicaciones con Flutter. Incluye ejercicios sobre estructura de programas, variables, colecciones, funciones, programación orientada a objetos, programación asíncrona, futures, streams y manejo de errores.

### Primeros pasos con Flutter

La carpeta `flutter_first_steps` contiene las primeras aplicaciones Flutter del repositorio. Estos proyectos avanzan progresivamente desde una app mínima hasta interfaces y flujos más completos:

- [Flutter Hello World App](flutter_first_steps/01_hello_world_app/README_es.md)
- [Flutter Counter App](flutter_first_steps/02_counter_app/README_es.md)
- [Maybe App](flutter_first_steps/03_maybe_app/README_es.md)
- [Tok Tik](flutter_first_steps/04_tok_tik/README_es.md)
- [Widget App](flutter_first_steps/05_widget_app/README_es.md)

Estos ejercicios cubren la estructura básica de los proyectos Flutter, widgets sin estado y con estado, componentes de Material, interacción, lógica sencilla de negocio, gestión de estado, peticiones a APIs, assets locales, reproducción de video, navegación, temas, piezas reutilizables de interfaz y uso de paquetes.

## Objetivo

El repositorio es principalmente un registro práctico de mi progreso como desarrollador Flutter. Los proyectos no buscan ser aplicaciones de producción; son ejercicios enfocados en entender conceptos, comparar enfoques y construir una base sólida para aplicaciones móviles más grandes.
